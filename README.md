# نظام إدارة الصيدلية (Pharmacy Management System)

منصة إلكترونية متخصصة لإدارة الصيدليات، تتيح للمستخدمين تصفح الأدوية وإضافتها لسلة التسوق، مع توفير لوحة تحكم متكاملة للمدير لإدارة المخزون ومتابعة الطلبات والمبيعات.

---

### وصف المشروع
موقع إلكتروني يتيح للمستخدمين تصفح المنتجات (الأدوية)، إضافتها إلى سلة التسوق، وإتمام عملية الشراء. يدعم الموقع إدارة المنتجات، الطلبات، وبيانات المستخدمين.

### فكرة المشروع
فكرة المشروع تقوم على توفير منصة بسيطة وفعالة لإدارة الصيدلية إلكترونياً، مع لوحة تحكم للمدير لمتابعة الأداء.

**أهم المزايا:**
* عرض الأدوية مع صورها وأسعارها.
* إدارة كاملة لسلة التسوق وعمليات الشراء.
* لوحة تحكم للمدير لمتابعة المبيعات وسجل الطلبات.

---

### طريقة التشغيل

1. **إعداد قاعدة البيانات:**
   * تأكد/ي من تشغيل خدمات Apache و MySQL عبر برنامج XAMPP.
   * افتحي `phpMyAdmin` وقوم/ي بإنشاء قاعدة بيانات جديدة.
   * استورد/ي ملف `pharmacy_db.sql` إلى قاعدة البيانات الجديدة.

2. **تشغيل المشروع:**
   * ضع/ي مجلد المشروع داخل مجلد `htdocs` في مسار XAMPP.
   * افتح/ي المتصفح واكتب/ي الرابط التالي:
     `http://localhost/Pharmacy-Management-System/`
